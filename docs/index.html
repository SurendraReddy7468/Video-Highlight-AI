Multimodal Analysis

Three domains.
Nine signals.

Unlike simple loudness-based cutters, Podcast VH understands what makes a moment compelling across audio, language, and visual dimensions.

🎙️
Audio
45% weight (podcast mode)
  • Energy — RMS loudness via librosa. Loud punchy moments score high.
  • Pitch variation — PYIN F₀ coefficient of variation. Excited speakers = high variation.
  • Pause detection — Dramatic 0.8s+ silences signal deliberate emphasis.
Signal weight45%
📖
Text
45% weight (podcast mode)
  • Keyword density — TF-IDF style scoring. Rare meaningful words rank higher.
  • Sentiment — Lexicon-based. Emotional extremes outscore neutral filler.
  • Hook detection — Open-loop patterns (questions, pain points) boosted. Solutions penalised.
Signal weight45%
🎥
Video
10% weight (podcast mode)
  • Scene changes — OpenCV frame diff detects camera cuts. More cuts = more dynamic.
  • Face detection — Haar cascade checks speaker presence per sampled frame.
  • Face position — Median center_x used for intelligent 9:16 crop alignment.
Signal weight10%

Usage

One command.
Any video.

Drop any local file or YouTube URL. The pipeline handles everything — no configuration needed.

PowerShell — Podcast_VH
# Generate a 30-60s vertical Short
$python main.py --input "podcast.mp4" --mode shorts

# Generate a 1-3 min highlight reel
$python main.py --input "podcast.mp4" --mode highlights

# Generate a 25-40s intro hook
$python main.py --input "podcast.mp4" --mode intro

# From YouTube directly
$python main.py --input "https://youtube.com/watch?v=XXX" --mode shorts
